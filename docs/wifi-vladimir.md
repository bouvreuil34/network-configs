# Wi-Fi-конфиг Владимира для Shadowrocket на macOS

Shadowrocket и рабочие VPN-серверы уже настроены. Этот файл заменяет только
конфигурацию маршрутизации: серверов, подписок и секретов в нём нет.
`PROXY` использует существующий сервер, выбранный в Shadowrocket.

Ссылка для импорта:

```text
https://raw.githubusercontent.com/bouvreuil34/network-configs/main/shadowrocket/wifi-vladimir.conf
```

1. Откройте Shadowrocket → **Config / Настройка**, выберите добавление
   конфигурации по URL, вставьте ссылку выше и дождитесь загрузки.
2. Выберите `wifi-vladimir.conf` → **Use Configuration / Использовать конфигурацию**.
   Проверьте галочку у нового файла: он должен стать активным вместо китайского конфига.
3. На **Home / Главная** оставьте выбранным свой существующий рабочий VPN-сервер.
4. В **Global Routing / Глобальная маршрутизация** выберите режим
   **Config / Настройка** и включите VPN.

Интернет-правила, их порядок, DNS и стандартные исключения локальных сетей
сохранены из `wifi.conf`. Обновления этого профиля загружаются по его собственному
`update-url`, указанному выше.
